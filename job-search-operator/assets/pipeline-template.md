## Application Tracker

Workflow: move each opportunity through the active statuses, recording the next
action at every stage.

Active statuses: Researching, Networking, Drafting, Ready, Applied, Interviewing, Offer.

Terminal statuses: Rejected, Withdrawn, Closed, Archived.

Decision mapping: Apply → Drafting; Network → Networking; Monitor → Researching;
Pass → Archived.

For an export, leave `Date applied` unchanged and record this in `Notes`:
`Exported YYYY-MM-DD: relative/resume.docx; relative/cover-letter.docx`.
Record a submission date or submitted status only after confirmation.
