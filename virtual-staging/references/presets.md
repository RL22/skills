# Interior Style Presets

Use these presets for AD-style virtual staging. Default 2x2 exploration order: Boho Warm Minimal, Mid-Century Modern, Scandinavian Neutral, Organic Modern Luxury.

## User-Provided Style References

When the user provides style reference images, links, moodboards, or descriptive text, analyze the reference before staging and output a new working preset in this format:

```text
## [Derived Style Name]

Source: User-provided style reference.

Style description:
[One concise paragraph describing the overall look, mood, materials, palette, furniture forms, decor density, and listing positioning.]

Best for:
- [Use case]
- [Room type]
- [Occupant type, buyer, or listing goal]

Visual cues:
- [Cue]
- [Cue]
- [Cue]

Prompt snippet: Stage the room in a [Derived Style Name] style with [materials], [palette], [furniture forms], [decor], and [overall mood].
```

Add the derived style to the current session's working preset list, then ask whether the user wants to use it in the 2x2 tile or as the consistent style across all photos. Do not edit this global preset file unless the user explicitly asks to save the derived preset permanently.

## Boho Warm Minimal

Best for: smaller spaces, apartments, studios, homes, warm natural light, younger demographics, creative neighborhoods.

Visual cues:
- Light woods
- Cream upholstery
- Jute or woven rugs
- Rattan accents
- Linen curtains
- Terracotta
- Olive tree or sculptural plant
- Soft layered neutrals
- Handcrafted ceramics
- Relaxed but polished styling

Prompt snippet: Stage the room in a Boho Warm Minimal style with light woods, cream upholstery, woven textures, linen, jute, rattan, terracotta accents, soft neutral textiles, plants, and relaxed editorial styling.

## Mid-Century Modern

Best for: urban homes or apartments, older units, hardwood floors, clean layouts, young professionals.

Visual cues:
- Walnut furniture
- Tapered legs
- Low-profile sofa
- Leather or boucle accent chair
- Geometric rug
- Sculptural floor lamp
- Warm brass
- Graphic wall art
- Clean horizontal lines

Prompt snippet: Stage the room in a Mid-Century Modern style with walnut furniture, tapered legs, a low-profile sofa, sculptural lighting, warm brass accents, geometric textiles, clean lines, and curated vintage-inspired decor.
